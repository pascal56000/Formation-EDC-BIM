1. Objectif du Guide

Ce guide est conçu pour les concepteurs de modules VR qui utilisent une application dédiée pour la planification et la scénarisation (planning, voix-off, quizz, hotspots). Il permet d'automatiser et d'organiser le transfert vers le logiciel Uptale Studio afin de supprimer les saisies manuelles longues et complexes.

⚡ Gain de Temps

Transfert instantané de dizaines de questions quizz et sous-titres via imports CSV batch.

🎯 Zéro Erreur

Standardisation des IDs, des coordonnées spatiales (yaw, pitch) et des consignes pédagogiques.

🤖 Injection RPA

Compatibilité avec des scripts d'injection automatique Playwright / Web Driver.

2. Format Pivot JSON de votre Application

Pour que votre application puisse communiquer avec les outils d'automatisation d'Uptale, votre export doit suivre la structure JSON ci-dessous : 

{
  "module_info": {
    "title": "Module VR - Sécurité Chantier BP Maçon",
    "author": "Pascal AMET",
    "language": "fr"
  },
  "scenes": [
    {
      "scene_id": "scene_01",
      "title": "Accueil Chantier",
      "media_type": "photo_360",
      "media_file": "360_accueil.jpg",
      "voiceover": {
        "text": "Bienvenue sur le chantier. Vérifiez vos EPI.",
        "audio_file": "voix_scene1.mp3"
      },
      "hotspots": [
        {
          "hotspot_id": "hs_01",
          "title": "Quiz EPI",
          "type": "quiz_question",
          "position": { "yaw": 45, "pitch": 0 },
          "content": {
            "quiz": {
              "question": "Quel équipement est obligatoire ?",
              "options": [
                { "id": "1", "text": "Casque avec jugulaire", "is_correct": true },
                { "id": "2", "text": "Casquette", "is_correct": false }
              ]
            }
          }
        }
      ]
    }
  ]
}

3. Convertisseur Automatique (`uptale_converter.py`)

Un script Python prêt à l'emploi est mis à disposition dans le projet :

python3 tools/uptale_converter.py script_source.json dossier_export

Il génère automatiquement :

  • uptale_quizzes_import.csv : Fichier CSV pour l'import groupé des Quizz sur Uptale Studio.
  • uptale_voiceovers_subtitles.csv : Script récapitulatif pour la synthèse vocale TTS et sous-titres.
  • uptale_media_manifest.json : Inventaire complet des médias (photos 360, audios, illustrations).
  • uptale_rpa_payload.json : Payload de configuration pour le script d'automatisation du navigateur.
